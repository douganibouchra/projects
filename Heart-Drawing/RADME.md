# Heart Drawing App ❤️

## Project Overview
A simple Python project that uses the Turtle graphics library to draw a beautiful heart shape on a black background, with the text **"I love you"** repeated throughout the design.

## Technologies Used
- Python
- Turtle Graphics
- Math Library

## Features
- Draws a heart using mathematical equations.
- Uses multiple scales to create a layered heart effect.
- Displays repeated "I love you" text inside the heart.
- Black background with pink text.
- Animated drawing process.

## How It Works
The application uses parametric equations to calculate the coordinates of a heart shape using sine and cosine functions.

The Turtle library moves across the screen and writes the text at calculated positions to create the final heart design.

## Requirements
- Python 3.x
- Turtle module (included with standard Python installations)

## How to Run
1. Install Python.
2. Save the source code as `heart.py`.
3. Open a terminal in the project folder.
4. Run:

```bash
python heart.py
```

## Project Purpose
This project demonstrates basic Python programming, mathematical functions, loops, and graphical drawing using the Turtle library.
